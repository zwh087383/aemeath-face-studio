# 原生资源优先的交流表演制作

输出可运行、可审阅的表演，而不只给一组看似合理的关节数值。区分原生素材事实、由轨迹推断的规律、自己选择的实现公式。用户指定的身体幅度、近身肘部、利落挥手等要求优先于通用风格建议。

## 先确认任务和资源

- 读取当前项目协作约定和文件认领；实验使用独立模块、独立页面，保留其它代理改动。
- 查本轮真实资源目录、动作/表情库和当前调度入口。文件名只能用于筛选，不能单独证明动作语义。
- **先选现成资源，再考虑重组，最后才新增。** 用户要求不重复时，列出最相近的原生与原创候选、相似点、关键区别及检查方式；没有完整语义标注时写明检索局限。改名、镜像、变速或添加随机噪声不算新动作。
- 原生待机作为底层不妨碍创作新反应，但要分别标明复用底层与新作层，不能把底层也称为原创。
- 在该项目工作前读 [references/project-integration.md](references/project-integration.md)。需要解读现有游戏资源时读 [references/native-evidence.md](references/native-evidence.md)。制作轨迹和过渡时读 [references/authoring-and-validation.md](references/authoring-and-validation.md)。

## 制作前写清表演意图

给出：触发条件、交流作用、参与部位、开始姿态、准备/主动作/保持/退出阶段、禁止触发情境、可中断方式。完整身体和动态表情应表达同一个交流作用，允许部位之间有设计过的先后。

- 情绪状态、交流意图、动作命令、实际播放状态是不同的数据。读取现有情绪权威源；不让角色表现模块修改长期情绪、人设或记忆。
- 不把每句字幕或每个音量峰都变成动作。无动作、继续保持和安静倾听都是有效选择。
- 手势必须有可理解的目的和收势；少量事件条件化变化优于不断随机摆动。
- 面部配方可以组合独立眉眼与嘴角，保留通道范围和有符号值。表情单侧通道缺省不自动等于清零另一侧。
- 说话时嘴形/发音通道由口型层拥有；表情层不覆盖元音、开合和发音闭口。眉眼、嘴角的竞争也须通过显式组合规则解决。

## 接入与衔接

- 复用已验收的模型加载、绑定、手臂求解和近身肘部约束。不要因新增微动作改变整个角色的手位或降低现有主动作幅度。
- 使用明确骨骼/形变遮罩与每帧唯一写入者，区分本地增量、mesh-space 增量、完整姿态。已烘焙成完整姿态的衣发不得再按 delta 叠加一次。
- 身体与配套衣发共享动作采样时间。只改身体骨可能使已有衣发失配，必须看实际蒙皮；不得宣称无碰撞算法也能保证不穿模。
- 语音绑定动作跟随实际播放游标，暂停/欠载时不偷偷推进。无语音的倾听、闲时、打断回落使用显式本地单调时钟。不要让音频停止把收势永远冻住。
- 语音cue带会话/轮次/response owner/epoch；倾听和闲时使用可信interaction/activity generation，不为无语音行为伪造responseId。两者都有来源、有效期、去重键及取消关联。外来取消也校验完整身份；受信本地撤销入口与外来消息分开。打断先撤销旧指令和音频，再从当前显示姿态平滑收势；旧包不能让已取消动作复活。
- 动作边车失败不能阻塞语音。执行指令与“已实际播放/已完成”的回执分开，不将队列接纳冒充历史交付。

## 必须留下的验收证据

1. **非重复说明**：查了什么目录、最近候选是什么、新增了哪种交流或控制能力。记录检索不覆盖之处。
2. **真实角色预览**：支持播放、暂停、拖动、正面/侧面/近景以及中途打断；可切换原有底层与新增层，便于判断新增作用。
3. **轨迹检查**：有限值、骨长/受保护骨不变、起止接缝、身体确实参与、不过度伸肘；说明阈值依据和坐标单位。
4. **面部检查**：检查真实形变权重及蒙皮画面，确认微表情可见、嘴形所有权不冲突。不以控制器写了数值替代可见效果。
5. **中断检查**：不同阶段打断均能返回；旧epoch被拒绝；暂停/恢复/反复触发不累积漂移。正常事件改变动作阶段时也检查姿态与速度接缝，不能只把默认演示时刻选在速度恰好为零处。
6. **实际时序与观感**：记录渲染条件和驱动耗时；至少看正/侧采样及运动预览。静态截图和几何阈值不能证明动画自然。没有人工连续观看时保留审美待验收说明。
7. **首帧加载与运行分开**：初始化记录资源请求、解析/绑定、贴图及着色器或首帧阶段，失败要能定位当前阶段。运行时分开采样控制、原生层、新层与渲染提交；CPU 提交耗时不当作 GPU 完成时间，跨批结果不能未经控制就称为优化收益。

局部实验无需修改正式语音链路或调用云模型。是否提交发布遵循当前用户授权与项目约定，skill 本身不新增外部操作权限。完成后报告实际实现、验证、限制和可直接打开的预览。
