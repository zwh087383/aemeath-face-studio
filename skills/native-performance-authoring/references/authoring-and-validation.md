# 轨迹、过渡与验收方法

这些是可选择的实现方法，不是已恢复的原游戏算法。先保留可靠参考轨迹，在缺口处新增有限参数。

## 制作顺序

1. 明确一个交流作用及触发/结束条件，选定稳定的起点和骨骼所有权。
2. 用少量有意义的阶段设计主体动作：准备、主动作、保持、恢复。身体与脸同一作用、不同时间分布；对动作阶段设计，不套全身固定lag。
3. 保持自然身体参与：头/胸/肩/重心相互配合。按任务小幅度制作，不能只旋转脖子来声称全身交流。
4. 手路径优先在已有解算器和经过验收的活动范围内改变。要保持肘部近身，同时看手掌朝向、袖口与脸/长发间距。
5. 表情使用独立通道的动态包络；静态pose权重只定义形状，先后、速度、保持另设计。不能为了“自然”不断眨眼或永久挑眉。

## 候选公式

- 形变表示：`v = v0 + sum(w_i * delta_v_i)`。驱动权重须遵守该通道语义，不把不同发音权重归一成概率。
- 五次混合权重：`u=clamp(t/T,0,1); w=6*u^5-15*u^4+10*u^3`。适用于权重渐入/退出，首尾一二阶导为0；不保证运动中的两个轨迹混合后速度全局连续，也不应磨平利落挥手的主节奏。
- 旋转用四元数slerp并保证符号连续，避免直接对Euler角跨±pi插值。
- 在明确“右乘局部增量”的坐标约定下：`delta = inverse(q_ref)*q_clip; q_out=q_base*slerp(identity,delta,weight)`。不要套到mesh-space层、不同绑定轴、或已烘焙完整姿态上。
- 打断可使用临界阻尼残差 `d(t)=(d0+(v0+omega*d0)*t)*exp(-omega*t)`，接续当前误差和速度；旋转误差须在合适的rotation-vector空间处理。它不自动解决身体碰撞或脚锁。
- 轻微不对称必须有交流目的。固定周期正弦不应同时控制躯干、手、头、眉眼。

## 测试要观察行为

- 用真实模型骨/形变检查实际输出，合成骨架可用于边界单测但不代替实模。
- 比较开启/关闭新层的相同底层时间点，排除原生呼吸/摆动冒充新增作用。
- 检查至少准备、峰值、恢复三个中断点，另检查立即中断与重复命令。
- 媒体暂停冻结媒体绑定cue；独立审阅页可提供明确的全局暂停。音频停止不冻结倾听、呼吸和打断恢复；恢复连续，新epoch不接收旧命令，结束后不残留偏移。
- 除取消外，准备中收到更正、等待中收到理解确认也须从当前姿态和速度接续。检查任意事件时刻的C0/C1接缝，避免专门选择速度为零的演示触发点掩盖折点。确认应门控“对方补充完成且已理解”，不能由VAD停顿或单一理解标记替代。
- 记录骨单位/角度单位与帧采样间隔。覆盖身体参与、手臂边界、口型隔离、是否发生突跳和状态漂移。
- 用视频/实时页面检查节奏，截图检查穿插与姿态；输出可量化结论与未验证的自然度/物理限制。
