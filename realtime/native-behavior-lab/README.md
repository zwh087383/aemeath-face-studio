# 原生行为衔接实验

这是动作准备工具，供制作和审阅人员把同源起势、循环、收势连起来，并在当前画面上取消。原生身体、手臂、长发与裙摆继续使用现有绑定；没有改变原始模型、游戏包、现有语音或记忆链路。

从 face 根目录运行 `node realtime/native-behavior-lab/server.mjs --port 18795`，打开 <http://127.0.0.1:18795/native-behavior-lab/>。完整执行准备入口在 <http://127.0.0.1:18797/action-execution-lab/>；从这一同源服务打开原生行为页可手动联动短表情。要求先有本机 `outputs/native-complete-20261022/manifest.json`、`outputs/action-preparation-20261023/review-queue.json`、原 GLTF 和 PMX。游戏文件与测量结果不随源码发布。

## 谁决定，按什么决定

- 来源计划由本地程序检查：保留完整源目录与骨架，不把另一个目录的同名 End 借来。319段身体按149个来源组保留，名称相同的组仍分开。
- Loop1、Loop2等变体保留原始阶段名，执行时明确归到循环阶段并放在End之前；每个变体独立重复指定次数。将两个变体顺序展示是审阅安排，未声称恢复游戏导演原来如何二选一。
- 人工选择组与起始条件，不调用模型猜用途。网页默认保留当前实际姿态与运动速度；首组没有前一姿态时采用本组首帧。也可以明确选择“本组首帧”或站姿起点作几何对照；这些均不证明站坐转换，持物、支撑、路线或另一人物不明确时继续保留待审条件。
- 播放器只读显式本地时间。身体、精确原生衣发与原生裙摆共享这一条进度；暂停冻结这条进度，拖动重建同一条轨迹。
- 现有 `NativeClip` 采样、`NativeRetarget` 标定、`NativeResourceLayer` 衣发层和 `NativeClothBinding` 同表面权重继续负责适配。衣发必须是精确名称及兼容骨架的原配；未找到时清楚保留缺口。

## 怎样接，怎样停

每段主体保留原速。接缝处先拿当前真正显示的姿态和运动速度，再与下一段轨迹计算有限时间的残差过渡。位置与四元数旋转都处理，旋转速度在同一个旋转向量坐标中求差，避免把不同朝向的角速度直接相减。

原生片段若含移动和转身，接下一阶段时按当前实际骨盆位置与朝向重定位，保留已经发生的水平移动和转向；源垂直运动仍保留，不凭空补椅高、落脚或支撑。源头骨盆方向过于特殊时仍须审阅，数值接续不等于已理解该动作。

“当前位置减速停住”撤销旧主体，从当前速度有限减速到当前附近的保持姿态。它不会跳回 Stand2。停住距离与转角有限，但这只是运动学停止：脚可能还没落地，坐姿可能没有椅子，手可能仍在物体旁；这些组不能因此自动使用。

“同源 End 接出预览”只在本组有 End 时可选。它通过同样的姿态/速度残差试接同源收势，不代表当前任何时刻都适合接入。低速点或端点相似都没有被当作接触或物体放置已完成的证据。

每次重建播放器都有新 epoch。旧 epoch 的取消会被拒绝；重复取消不会再开一次动作。这里只提供受信本机审阅入口，尚未声称接通正式会话/回复 owner、语音交付与历史记录协议。

从一个正在运动的真实画面接到另一个动作时，必须同时传入 `initialPose` 和 `initialVelocity`；只复制姿态会丢掉原来的运动速度。`scripts/action-preparation/validate-native-moving-entry.mjs`用预先载入的实际模型资源验证这条路径。暂停时显示没有移动，入场速度应取零。

预先载入与现场等待读盘要分开：播放器可以在资源已就绪后继续真实姿态和速度，网页换组等资源时会保留最后画面；这段加载停顿没有被计作自然连续转场。正式调度应提前准备候选资源，再决定切换，不把异步读盘冻结藏在“平滑进入”里。

## 怎样验证

`node --test tests/native-behavior.test.mjs tests/native-behavior-server.test.mjs` 检查不同旋转轴下的姿态/速度接续、有限停止、暂停与拖动、旧 epoch、同目录来源和只读本机服务。

`node scripts/action-preparation/validate-native-behaviors.mjs` 使用真实 PMX、真实 GLTF 层级与蒙皮、原生衣发及裙摆，对全149组/319段执行。每段20%、50%、80%分别取消，另检查完整阶段接缝、有限矩阵、骨长和抽样蒙皮；结果写到本机 `outputs/action-preparation-20261023/native-behaviors/execution-all-groups.json`。

`node scripts/action-preparation/validate-native-behavior-world.mjs` 再对真实目标骨的世界位置和旋转求左右速度，不用只检查局部控制量来代表实际身体。结果写到同目录 `world-all-groups.json`。

这一世界坐标验收还会逐个检查循环2次与3次、真实裙片抽样蒙皮的取消接缝、取消最终是否停住，以及过渡结束后主体局部姿态是否仍与原生原速采样一致。

截至本批冻结，当前源码指纹的全组世界验收已通过：149来源组、319段身体、1665次阶段取消、192个重复循环场景、2464个世界接缝检查、22569个真实姿态样本。319段身体与21段精确衣发的数据哈希均与准备队列相符，参与测试的13项本地依赖与这340份数据均早于本次测试开始。具体证据在本机 `final-summary.json`、`integrity-current.json` 与 `world-all-groups.json`。旧 `execution-before-loop-fix.json`、`world-before-loop-fix.json` 和中间部分报告保留历史，不能代替当前结果。

浏览器验收脚本 `scripts/action-preparation/browser-native-behaviors.cjs` 在独立 Chrome 里检查代表组的实际取消、暂停、骨长、衣发、裙摆与正侧画面。`browser-native-continuous.cjs` 录制原速连续播放、同源收势及缺 End 停止。截图和录像不是所有动作自然度、碰撞或物理支撑已经通过的证明。

当前独立浏览器9组/66个取消点通过；`native-continuous-current.webm` 包含Talk02完整起势→两遍循环→收势，以及思考、缺End拨发和同源End取消，最终均到达对应保持状态。联合短表情由统一入口人工指定，尚未声称由正式情绪和对话自动调度。

## 继续接入前仍要做的事

逐组确认真正用途、现场与可退出阶段；补可靠的接触、落脚、起坐与物体交接过程；对常用组合连续观看、修正；再接统一调度与正式会话取消保护。所有组当前均 `automaticEligible: false`，没有将“资料齐、数值连续”当作自动使用许可。
