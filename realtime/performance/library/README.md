# 爱弥斯表达图书馆（实验性扩展，2026-10-22）

本轮在已有控制器、骨骼解算和衣发避让基础上增加可复用内容，并提供集中预览。原有 16 个身体动作的编排参数不变，尤其保留身体幅度、近身肘部和利落挥手。这里的“大动作”指站定时胸肩、重心与双臂共同展开；尚不包含走路、跳跃、转身位移或接触物体的动画。

## 内容数量

| 类型 | 原有 | 新增 | 合计 |
| --- | ---: | ---: | ---: |
| 身体动作 | 16 | 40 | 56 |
| 面部表情预设 | 8 | 32 | 40 |
| 头部短动作 | 5 | 12 | 17 |
| 连续表演编排 | 7 | 16 | 23 |

连续片段复用身体动作、表情和头部动作，并加入停顿、收势与接续；不应把它们统计成额外的独立动捕素材。新增 16 段共 149 个步骤，其中 49 个步骤没有身体手势，避免从头到尾一直比划。

新增身体动作分为：

- **12 个细微反应**：轻点头、双点头、专注侧倾、重新聚焦、思考一瞥、抬眼回忆、迟疑侧头、呼吸落定、重心落定、松开手指、安静倾听、轻微摇头。
- **12 个交流手势**：交出话轮、邀请继续、澄清、对比两个选项、列举两点、勾勒范围、向下强调、温和拒绝、安抚、询问确认、向左/右介绍。
- **10 个情绪动作**：释然、小小自豪、失落、害羞、怀疑、欣喜、担心、下定决心、感谢、忍俊不禁。
- **6 个较大连续动作**：热情迎接、连续解释、克制庆祝、讲述一段故事、调整后再出发、依依告别。

32 个新表情涵盖交流回应、关怀、思考、确信、玩笑、迟疑与疲倦；12 个头部动作包含轻应、双点头、低头听、抬下巴、左右转看、向上/下看、头部落定、轻摇头、小幅同意、思考侧倾。使用的是模型已有形变与头部通道，没有伪造眼球独立追踪能力。

## 预览

在项目根目录启动已有本地服务：

```powershell
node realtime/avatar-server.mjs --port 18788
```

打开 `http://127.0.0.1:18788/performance/library/`。本机需要已有模型、贴图及 `preview` 的 Node 依赖；本批不包含模型素材或私人音频。

页面可按四类内容、细分类别、名称/ID 和“本轮新增”筛选；支持上身、侧前、侧面、全身与面部视角。可以调整力度和速度，独立检查表情联动，以及无声口型叠加。

优先看“从招呼到交谈”“先听，再安慰”“讲一段小经历”“从犹豫到达成共识”。原有“近身挥手”仍可用于对照普通挥手与轻快招呼。

新片段在默认速度、放松姿态开始时约 28–55 秒；改变速度、起始姿态或遇到动作冷却后会变化。开启循环时新增片段最多两遍。旧片段保留原有循环语义。

## 触发与调度

预览直接使用实际 `MotionController`、`FaceController` 和 `PerformanceDirector`，不调用模型、不采集麦克风。

```js
director.play('warm_welcome');
director.playExpression('skeptical', .65);
director.playAction('double_nod', { intensity: .6 });
director.playStory('quiet_comfort', false);
director.pause(); // 再调用恢复
director.stop();  // 撤销未来步骤，从当前身体姿态收回
```

以上为各自独立的操作示例。成功的手动操作会接管旧表演；连续调用它们会依次替换，而非把四段播放排队。

连续编排每一步可同时指定：

```js
{
  gesture: 'reassure',
  face: { preset: 'empathy', intensity: .6, duration: 2.5 },
  action: { action: 'acknowledge', intensity: .35, offset: .4 },
  rest: .7,
  waitForRecovery: true
}
```

`gesture` 可省略以留下安静的表情/头部回应；`delay` 控制起步前等待，`rest` 控制步骤后的留白，`duration` 给步骤设置最短停留，`offset` 给表情/头部动作设置相对偏移。身体动作本身包含眉眼表情包络；语音口型仍走原有独立混合通道。

所有步骤共用可暂停的本地时钟及 epoch。新表演接管、停止或外部音频所有者切换后，旧步骤不得复活。最后一步完整收势后才结束或重复。动作冷却检查仍在，拒绝的新请求不会破坏正在播放的片段。

`AVATAR_CATALOG` 已暴露所有 56 个身体动作、40 个表情和 17 个头部动作，供现有实时调度器调用；原命令顺序与原默认参数保持不变。**云端 Qwen 的提示词和工具白名单本轮未扩容，也未做新的云端对话测试**。模型主动选择新动作仍需后续显式接入，不能把本地可播放等同于模型已经学会使用。

## 文件

- `preview/core/expanded-motion-library.js`：新增身体动作与描述；由 `motion-profile.js` 合并。
- `preview/core/expanded-expression-library.js`：新增表情/头部动作；由 `profile.js` 合并。原八段固定演示仍用旧预设。
- `realtime/performance/expanded-sequences.mjs`：16 段连续编排。
- `realtime/performance/director.mjs`：统一时间线、手动接管、暂停和撤销。
- `realtime/avatar/controller-bridge.mjs`：实时调度器命令目录。
- `realtime/performance/library/`：本预览页面。
- `scripts/check-expanded-motion.mjs`：实际 PMX 的离线表面间距采样。
- `realtime/browser-expanded-library.cjs`：真实浏览器的模型加载、动作、暂停、打断、口型、界面与录像验收。

## 验证及边界

测试命令及最终结果见 `docs/expanded-performance-library-2026-10-22.md`。验证包含原动作数据指纹、真实 PMX 骨骼、连续性、全部新增片段、调度器接线和真实浏览器预览；不以“配置里有这个名称”代替实际执行。

衣服与头发的物理模拟沿用关闭状态。离线表面检测是采样与近邻法，不能证明所有帧、所有动作混合、所有强度都绝无穿插。程序测试能约束跳变和数值问题，动作是否自然仍需主观观看；新增内容是手工编排的程序动画，尚不等同于专业动捕或动画师逐镜头精修。

“测试口型”只有本地合成开合，没有真实语音。暂停测试时闭嘴，停止后关闭该测试；未声称通过本轮真实语音或声学验收。原始截图、录像、骨骼采样只保存在本地 `outputs/expanded-library-20261022/`，不上传模型及音视频。
