# 肘部与身体联动第二版 · 2026-10-16

实验分支：`codex/natural-elbows-body-20261016`。比较基线是上一版已发布的 `63199b1fdf06c33de21f448f3c2bc66cf7ffb2a2`。用户实际观看后指出肘部过于外张、部分动作只有手臂动，身体没有可见反应。本批直接修正这两项问题。

## 行为变化

- 低位对话手势的肘弯曲平面结合自然下垂方向；手部目标不被强行拉回。高位挥手、胸前接触和近伸直手臂保留必要空间。手腕姿态编译预留余量，运行时安全上限和旧测试断言不变。
- 重编 16 个身体轨道。解释先蓄势再倾身，挥手带动胸肩与侧向重心，耸肩有胸部后撤和回落，抚胸带腰背前倾；停留阶段仍有有目的的姿态发展。保持原动作时长、重点时间、阶段划分和表情轨道。
- 预览默认循环“身体联动”，便于直接看解释、挥手、耸肩、抚胸、俯身和仰头。页面标题标明第二版。
- 实际渲染诊断补充上胸、髋部、上臂根和肘位置。浏览器逐动作验收要求真实上胸旋转至少 4°，长停留动作也必须继续变化，不能再用头动或极小非零骨骼数值替代身体参与。

## 前后测量

使用同一 PMX 骨架、同一自然站姿、关闭随机呼吸微动、正常速度与力度。肘部外移在胸部坐标中相对上臂根计算；抬高的挥手主臂不套用低位手势标准。数值来自完整轨迹，不是单张截图。

| 原有动作 | 上胸最大旋转：前 → 后 |
|---|---:|
| 解释 | 1.9° → 11.2° |
| 挥手 | 1.6° → 9.8° |
| 耸肩 | 0.6° → 7.6° |
| 抚胸 | 1.6° → 12.7° |

最终肘部、网格、浏览器、连续动作及打断结果见同目录 `elbow-body-validation.json`。第一版的 `VALIDATION.md` 和 `validation-summary.json` 保留历史，不冒充此次重新验收。

普通解释、害羞、思考、安慰、郑重点明的目标侧肘外移减少约 **25～27%**；对应外展峰值由约 37～41° 降至 **26.5～29.0°**。高位挥手主臂仍能抬起，未用统一夹肘姿势取代动作意图。

净空调整修正了解释辅助臂、俯身手指和招呼辅助臂的新增接触。80 个固定姿态的最终结果是：命中 14/80、最大手部标记 0、袖部标记 19、最大深度 .111 模型单位；基线分别为 14/80、0、0、.087。**命中姿态数量相同不代表无退化**，命中部位已有变化。

额外检查 `wave @ 2.5s` 发现新袖子与辫子接触：基线 0，当前 16 个顶点、深度 **.223** 模型单位，部位 `左袖子_13_0 → 左辫子A10`。它不在 80 个固定采样点中，所以 .111 不能描述为全局最大值。已另保存这个保持姿态的侧前和侧面截图；这是尚未消除的局部衣发限制。胸前动作等也仍有袖发接触信号，未以恢复夸张外张、削弱身体动作或放宽检测阈值掩盖。

## 本次测试的特殊性与边界

这是本地、无声的动作修正和真实 PMX 渲染验收。所有对比使用相同模型、材质与镜头；基线浏览器只替换四个动作核心模块为 Git 基线版本。额外口型检查是无声合成嘴形叠加。没有调用 Qwen、麦克风、音频生成或完整 WAI 记忆流程，没有重新测量语音全链路延迟。

衣发物理仍关闭。最近顶点/法线网格检查是启发式，采样姿态和观察视角不能证明所有动作无穿模。数值和回归保证被测行为，不代替对动作自然程度的实际观看判断。本次未修改 Claude 尚未交付的 studio 页面，也未把此前未完成的 `realtime/wai/` 或其他共享改动纳入发布。
