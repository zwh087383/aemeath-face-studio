# 近身肘部、轻快挥手与袖发回收修正

日期：2026-10-16。实验分支：`codex/close-elbows-crisp-wave-20261016`。比较基线为上一版已发布的 `69ba75685596ee86c7697352fed9e08875a60fe7`，不是最初四手势版本。

本轮针对观看反馈：挥手收回时左长袖扫入后辫子，高位肘部仍太靠外，轻快招呼的手部挥动不够利落。保持上一版胸腰与头部表现幅度，进一步收肘、加快挥动，并检查普通收回和中途打断。

这是**实验性本地人物动作修正**。此次没有运行 Qwen、WAI 记忆检索、麦克风或真实语音链路；测到的收势时间是视觉动作恢复时间，不是语音停声延迟。

## 实现

- 普通动作增加自然下垂方向的权重；高位挥手让上臂向前弯，降低向两侧撑开的程度。胸前掌锚动作保留前方空间，避免收肘后上臂贴入胸部。
- 模型是不对称服装，实际有五条左长袖骨链，没有右长袖骨链。它们直接挂在上臂，关闭物理时会整片随上臂扫动。对真实袖根施加有上限的衣料姿态约束，让长袖朝裙外、辫前的空间顺应。保留挂点、不隐藏模型、不为衣物外推肘部。
- 衣袖修正进入与手臂相同的局部旋转映射，真实 `MotionRig` 与数值蒙皮使用同一份结果。它是运动学约束，不是布料物理模拟。
- `wave` 加快重复挥动，`greet` 改为短促招呼。高位手轨道向内移，保留挥动摆幅；只重排必要的身体关键帧时间，身体数值不变，其余十四个公开动作配置不变。
- 默认预览改为“近身挥手”：完整挥手、完整收回、轻快招呼、完整收回。其他连播保留原来的接续方式，便于分别观察自然收回和连续动作。

## 同条件的前后对比

真实控制器在默认速度、关闭自然微动、同一 cue ID、60 FPS 下执行，再测量 PMX 骨骼的实际运动。配置时长不等于实际播放时长：抬手/收回有路程伸缩，cue ID 也有确定性的微小速度差异。

| 指标 | 上一版 | 本版 |
|---|---:|---:|
| wave 挥动完整周期频率 | 约 1.94 Hz | 约 3.00 Hz |
| wave 完整播放时间 | 3.983 s | 3.567 s |
| greet 完整播放时间 | 3.633 s | 3.183 s |
| wave 上胸峰值旋转 | 9.818° | 9.848° |
| greet 上胸峰值旋转 | 11.105° | 11.130° |
| wave 头部最大位移 | .43659 | .43769 |
| greet 头部最大位移 | .77843 | .77976 |
| wave 挥手侧肘部最大外移 | 2.37224 | 1.64175（减少 30.8%） |
| greet 挥手侧肘部最大外移 | 2.28582 | 1.45577（减少 36.3%） |

`greet` 是一次短招呼，不能将单次反转间隔换算后称为持续频率。以上位移单位为模型单位。肘部前后对比、密集网格与最终浏览器证据汇总见同目录 `crisp-wave-validation.json`。

wave 检测到的全部极值还包含起始过渡中的一个小反转，原始估计为 2.951 Hz；四个主要极值间距约 .1667 秒，对应约 3 Hz。原始数据保留这个额外极值。

## 验收与证据边界

回归覆盖实际骨骼、身体幅度、手部反转、暂停、取消、渲染一致性和既有实时调度；原有手关节、安全范围及连续性要求没有放宽。旧测试中要求高位肘必须向外超过 1.8 单位的规则，按用户明确要求改为向前弯且外移小于 1.8；抬手高度仍保留要求。动作目录改为跟随当前动作定义的时序，不再强制使用旧挥手重点时间。

- 完整 Node 回归 274 项通过，无失败或跳过；随后增加扫描恢复文件的 FPS/模式校验，并补跑相关专项。具体命令与回执见 JSON。
- 真实 PMX 浏览器 16 动作与暂停、替换、合成口型等 23 项通过；wave/greet 完整播放及两动作四阶段共 8 次打断通过。专项实际胸部峰值 9.846° / 11.145°，取消后完成收势约 814–1101 ms。
- 连续数值验收覆盖三种起始姿态 × 两个动作 × 普通完成及四阶段取消，共 30 条路径。袖发每 60 FPS 帧检测，全身接触每 6 帧检测；另有放松姿态下每 .025 秒的 99 个唯一保持姿势。三姿态运行中重复执行的相同保持姿势不重复计为覆盖。
- 30 条路径的 5,561 个袖发帧、925 个全身采样帧均没有袖发/袖身标记，99 个保持姿势的袖发、袖身、手标记也为零。基线只完成了 19 条路径并明确保留 partial；没有冒称完成同样 30 条基线。
- 浏览器完整验收首次因材质加载后的三帧等待 15 秒超时，0/0 项，保留失败记录；原脚本原阈值复跑 23/23 通过。专项首次错误要求不存在的右袖节点，核对 PMX 后修正为真实左侧五链并重新通过。这些首次失败没有计为通过。

测量期间四个动作核心的 SHA256 一致。发布前只删除 `motion-skeleton.js` 的多余文件末尾空行，已核对 `trimEnd()` 后逐字相同，并记录测量/发布两个 SHA256；清理后近肘/袖骨/扫描恢复专项 9/9 通过。原始网格与浏览器回执保留原测量 hash，不改写为发布 hash。

袖发检测使用真实 PMX 顶点、原始蒙皮权重及所有局部变换，保留每个袖发顶点。检测是在 .3 模型单位的近邻范围内检查法线方向深度，超过 .03 标记；它不能代替三角形碰撞或全角度人工观感判断。还检查袖与身体、裙摆、飘带的接触，避免把问题从头发挪到其他部位。

原始证据位于 `outputs/crisp-wave-20261016/`，包括独立基线、连续轨迹、保持姿势、浏览器截图及视频。视频录制、并行网格扫描和多个预览会影响帧率，本轮不把这些窗口的 FPS 当成单实例性能基准。衣发物理仍关闭；肩部飘带与侧发的少量接触属于已记录的剩余限制，不能声称全模型零穿插。

另外，倾听姿态起手时仍有左指尖—裙摆的既存接触信号。同 cue、60 FPS 的前 .8 秒对照中，标记帧 8→2、累计顶点帧 90→14，最深法线信号 .212→.246 模型单位；持续更短但单点深度略增，不能称所有接触指标都改善。当前集中于 t=.400/.416667 秒，其他起始姿态与 greet 的采样中未见这类手部信号。本轮未继续调整这段既存手裙路径，避免把袖发修复扩展成另一轮动作重编。

可复现命令见 [README.md](./README.md)。新测试依赖的 `scripts/check-motion-clearance.mjs` 是 Claude 2026-10-14 已完成交付的检查工具，本次原样纳入仓库；新检查通过 `skinCoordinated` 支持当前全身旋转及平移，未修改旧工具的历史算法或阈值。
