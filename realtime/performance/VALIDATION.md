## 运行测量

本机 RTX 5070 Ti Laptop GPU，Headless Chrome 155，1440×1000、像素比 1，衣发物理关闭。关闭其他测试浏览器、结束录像后单独测量 15 秒：

| 指标 | 数值 |
|---|---:|
| 采样帧数 / 时长 | 1890 / 15003.8 ms |
| 浏览器帧率 | **125.97 FPS** |
| 动作、脸部合成及赋值 CPU p95 | **0.60 ms** |
| 渲染提交 CPU p95 | 7.90 ms |
| 帧间隔 p95 / 最大 | 10.10 / 13.50 ms |

这是浏览器帧回调和主线程提交耗时，不是物理屏幕刷新率、GPU 完成时间或语音端到端延迟。内置浏览器、窗口大小和并发负载会改变实际读数。

实际浏览器专项测量：

- 无声 `laugh` 暂停观察 56 帧，嘴部开口、骨骼位置和旋转最大变化均为 **0**。
- 无声 `laugh` 取消后首帧仍保留开口，最大逐帧开口变化 **0.00912**；约 **1277.7 ms** 完成动作与笑容回收。这是有意保留的自然收势，不是语音停声延迟。
- `bow_smile` 表达阶段换成 `look_up`，旧动作进入回收、新动作开始，最大腕部单帧位移 **0.08641 模型单位**。
- 合成测试口型 183 帧：元音及宽/窄/平口与语音控制器输出的差为 **0**，同时存在笑眼和嘴部开合。
- 旧 avatar 的本地 WAV 取消：**77.2 ms 收口、920 ms 收势**，音源数归零；暂停期间表情层未重新张嘴。
- Qwen 假桥回归：**86.1 ms 收口、827.3 ms 收势**；不属于新的真实云端结果。

## 修复与限制

实际测试发现并修复：旧 body 字段截断；新较大动作收回残差；无声轻笑暂停/取消时被语音闭嘴保护误伤；预览连播被 cooldown 拒绝后提前更改序列状态。测试也推动调整了 surprise 手腕、think 手姿、greet 回收和 bow 手指距离。

`look_up` 世界头部/上胸俯仰约为 −0.261/−0.118 rad；`bow_smile` 约为 +0.168/+0.338 rad。后者头部相对上胸抬起，身体仍保持俯身；不是世界坐标完全仰脸。双脚采用支持链约束，手臂跟随实际胸部变换。

衣发物理关闭，右肩飘带与侧发仍可能接触。近邻顶点/法线启发式和三个观察角度不能证明所有姿态无穿模。16 个动作包含相近的对话手势；自然程度仍需由实际观看判断，不能用数量或 FPS 代替。

此批没有新 Qwen 调用，没有新麦克风测试，也没有完成或复测 WAI 记忆检索全链路。此前未完成的 `realtime/wai/` 和共享 WAI 改动保留在本机，未混入此发布。新动作已可通过统一 scheduler 指令调用，但字幕旁路仍沿用旧选择规则，尚未把 16 种动作都映射到自动字幕规则。
