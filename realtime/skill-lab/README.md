# 等你改完，再确认

一次实际使用 `native-performance-authoring` 技能的独立制作实验。原创内容是“回应准备 → 察觉对方更正 → 收住并等待 → 补充完成且理解后确认”的事件条件化表演，包含身体与动态眉眼；原生 Stand2 / Rib_Stand2、PMX、原生 GLTF、骨骼适配与手臂解算器是复用内容。

## 打开

在 face 项目根目录运行：

```powershell
node realtime/skill-lab/server.mjs --port 18793
```

打开 `http://127.0.0.1:18793/skill-lab/`。服务器仅监听本机，沿用现有资源服务器的只读别名。需要本机现有私有模型和原生导出资源；源码不携带游戏素材，也不调用云模型。

页面提供暂停/播放、拖动、正面/侧面/斜侧/近景、同一底层时刻的新层开关和手动阶段中断。完整演示在 0.64 秒发送更正事件，在 2.65 秒发送“补充结束且已理解”事件；手动模式不自动确认。单纯时间经过或 VAD 静音不构成理解或说完的证据。

## 制作意图与决策

技能读取覆盖主文件、project-integration、native-evidence、authoring-and-validation。遵照“先现成、再重组、最后新增”，先检查当前目录与原创库，选择了原生片段和现有固定时长原创动作尚未表达的条件化交流过程。

触发场景是角色正要回应时，对方说“明天……不对，是后天”。准备阶段右手低位抬起、胸部稍前送、眉眼抬起；更正发生时从当前姿态和速度收住，身体略退、掌心转为开放，目光留在对方；保持阶段不点头、不周期性摆动；获得完整可信完成事件后，身体前倾并点头，眉眼舒展、嘴角随后出现，最后回到原生待机。腿脚由原生底层持有，本新层不改变骨长或脚位。

禁止把未解决的理解歧义、仅 VAD 停顿、其他层占有说话或移动时的状态当作确认。正常事件与中断都继承当前速度，用五次 Bezier 的控制点凸包约束保证各通道不超出设计范围；部位各自使用有界收敛时间，不统一套全身延迟。这个函数是本次实现选择，不声称恢复了游戏制作公式。

嘴形发音层继续拥有开合、元音和闭口。新表情只写七个明确映射的眉、眼和左右嘴角通道，保留两侧差异，不归一化、不改其他形变。页面的「あ = 0.32」测试开关模拟另一位写入者，供隔离检查。

## 最近候选与新颖性边界

本轮当前资源目录为 583 段动画（319 身体、245 衣发、10 道具动画、9 注视）和 3142 项资源。现有原创库为 56 个动作、32 个扩充表情目标。实际读取了 17 个原生角色表情的 108 条曲线，全部为时间上恒定的组合姿态。

| 最近候选 | 相似处 | 本次新增的过程 |
| --- | --- | --- |
| 原生 Thinking01 Start/Loop | 安静等待与思考姿态 | 等待来自对方自我更正，确认依赖独立完成和理解事件 |
| 原生 Talk01 / ShowHand01 Start/Loop | 身前手势与开放掌心 | 在任意准备时刻收住，可等待到有效期（默认 18 秒），不由片段时长决定点头 |
| listening_pause / offer_turn | 留白和把话递给对方 | 先察觉更正再收住已开始的回应，显式追踪原轮次和取消关联 |
| ask_check / clarify | 提问、聚焦或澄清 | 本次没有提出新问题；等待对方完成已有修正后才确认 |
| embarrassed | 想解释又收手 | 没有羞涩躲视，等待不是固定时长，也不自动转回解释 |
| reset_and_resolve | 整理后表达决定 | 解决信号来自外部完成/理解事件，不来自自定时间 |
| micro_ack | 小幅确认 | 确认之前存在可中断、可持有的更正处理阶段 |

全部当前目录条目的名称、分类、来源与分组字段被检查；七个最近原生身体候选实际解码并采样了头、胸与右臂世界轨迹。没有逐段人工观看所有游戏动作，也没有覆盖未提取内容。因此新颖性声明限于当前检索范围内的条件化过程及独立编写的轨迹组织，不能宣称每个姿势或全游戏语义绝无相似。

## 实现与所有权

- `preview/core/skill-reaction.js`：纯事件控制器、阶段采样、边界、形变遮罩、确定性审阅脚本。
- `realtime/skill-lab/viewer.mjs`：现有 NativeClip / NativeRetarget / NativeResourceLayer / NativeClothBinding 加载与绑定，独立新层组合及观察界面。
- 身体与配套衣发共用显式采样时间；已烘焙的原生衣发按完整姿态使用，不再次作为增量叠加。
- 新层只在 PMX 当前帧的原生姿态上写局部上身增量、右臂完整姿态和限定的 PMX append 辅助骨。手臂使用既有近身肘部解算器，辅助骨使用模型真实 grant 系数，不修改既有挥手或主动作幅度。
- NativeRetarget 每帧恢复全部局部变换后再组合，避免上一帧累积。新层没有长期情绪、人设、记忆或 WAI 在线状态写入。
- 命令包含 sessionId、turnId、epoch、source、expiresAt、dedupeKey 和 cancelId。外部取消需要完整身份；无参 interrupt 是受信本地取消。接纳回执与实际完成回执不同。

`window.skillLab` 暴露 snapshot、play、pause、seek、restart、manual、correction、confirm、interrupt、setEnabled（setLayer 别名）、setView、setSpeech、boneSample，以及 mesh/source/controller/renderer/camera。confirm 外来事件必须同时携带 `understood: true`、`speakerCompleted: true`、`partnerVoicing: false` 和匹配身份。加载诊断包含阶段、四项资源的成功/失败、耗时及贴图进度。

## 验证与限制

运行 `node --test tests/skill-reaction.test.mjs`：12 项通过。覆盖未完成保持、理解/说完独立门控、接纳/完成回执、暂停、中断、完整外来身份、旧 epoch、重复命令、有限值、嘴形遮罩、零残留、延迟帧的完成/超时顺序，以及 40 组随机时刻的更正/确认/取消 C1 和范围测试。

运行 `node realtime/skill-lab/audit-resources.mjs` 可复现资源比较，原始证据写入私有 `outputs/architecture-skill-20261022/forward-test/`。`inspect.cjs` 是作者截图检查入口。首次作者浏览器运行在 120 秒 ready 等待处超时，已关闭该测试浏览器；父代理首轮随后在约 171 秒后完成真实模型加载，9 项实模检查通过（姿态、开关、5 阶段中断、嘴形隔离和重复无漂移），侧面与近景截图已由作者查看，低位手掌、近身肘部与表情可见。该首轮证据早于完整门控/C1/grant 修复，最终版本由父代理另行复验，不把首轮结果冒充最终状态。

首轮实模为 RTX 5070 Ti，整体 render 调用墙钟中位约 55 ms、P95 约 95 ms，不能声称 60 FPS。最新页增加轻量分段计时：controller（时钟/状态采样）、native（原生身体/衣发/绑定）、reaction（新身体层）、face（眉眼/嘴角）和 render（相机/渲染提交）。这些是 CPU 墙钟及提交耗时，不能等同 GPU 完成时间；最终测量以父代理浏览器验收为准。

最终冻结版本执行 `node --test tests/skill-reaction.test.mjs tests/native-motion.test.mjs tests/native-cloth-binding.test.mjs tests/native-resource-layer.test.mjs`，29/29 通过（其中新增控制器 12 项）。执行 `node scripts/browser-skill-lab.cjs`，11/11 浏览器检查通过、0 pageerror，9 个相关源码文件的测试前后 SHA-256 相同。真实 PMX 验证包含受保护肢体不变、同一底层时间开关新层、重复操作零漂移、五阶段打断、过期身份拒绝、说话未完成不确认，以及全阶段保留「あ = 0.32」。C1 检查是数值容差内的参数轨迹连续性，不等于证明最终 IK 与蒙皮全程严格 C1。

最终窗口为 RTX 5070 Ti Laptop、1051×690、pixelRatio=1。最后 300 帧的新增身体层中位 0.4 ms / P95 0.6 ms，包含原生采样、控制、表情和渲染提交的 CPU 总墙钟中位 9.4 ms / P95 12.0 ms；首次模型就绪 51.477 秒。首轮与最终轮不是受控性能 A/B，不能把加载时间差或整帧差直接归因于本轮修复，也不能将 CPU 提交耗时当作 GPU 帧率或语音响应延迟。最终原始数据、截图和 5.2 秒静音录像位于私有 `outputs/architecture-skill-20261022/browser/`。

此页尚未连接 WAI 正式事件、语音播放游标或生产导演。新动作是无语音的倾听反应，用本地单调时钟；页面的全局审阅暂停也冻结收势，恢复后继续，这不表示生产中的音频暂停应冻结本地收势。未实现运行时碰撞或物理，配套原生衣发无法证明与所有新姿态绝不穿插。最终画面、实际输出骨位、形变可见性、暂停和中断已有浏览器证据，连续自然度仍需用户审阅。

## 使用技能时发现的不足

1. 参考曾把实际 `motion-profile.js` 写成 `motion-profiles.js`；已向父代理报告，由技能作者修订。
2. 技能说从当前姿态平滑收势，但没有明确要求正常 correction/confirm 事件也继承速度。独立审阅发现初版仅位置连续后，本次实作补齐 C1 和随机时刻测试。
3. “旧 epoch”之外还应显式检查 session/turn/cancel 关联；“理解确认”之外还需要独立的说话完成事实。本次通过独立审阅补齐，建议技能加入这些反例。
4. 三维首帧加载应拆成资源、绑定、着色器阶段记录，以便区分初始化问题和动画问题；本页已增加诊断。
