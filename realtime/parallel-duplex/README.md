# P 方案：记忆、双工语音与动作调度实验

这是独立实验，不是正式应用入口。语音回复、动作建议分别使用独立的 Qwen Audio 3.1 Realtime 连接；语音不等待动作模型或动作回执。实际 WAI 检索、已送达上下文、后台解析、按需完整回复转交和历史确认沿用原实现。

## 怎么运行

在仓库根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File realtime/parallel-duplex/Start-ParallelDuplex.ps1 -UseLocalProxy
```

`-UseLocalProxy` 只使用已有的 `127.0.0.1:7890`，不更改系统设置或凭据。没有该代理时省略参数。WAI 的 Python 和配置由 `Resolve-Workspace.ps1` 查找，运行数据放在机器本地独立实验目录。

页面：`http://127.0.0.1:18803/parallel-duplex/`。打开页面、音频检查和本地预览不请求模型；点击连接、运行真实测试或开启麦克风才进入相应云端流程。

本批最多 6 个 WAI 对话轮次、24 个 Qwen 响应，监听、语音、动作、转交都计入。后台既有解析调用另记，不属于这 24 个实时响应。未知用量会停止新调用；脚本不会重置账本、覆盖旧数据或暗中补测。已用过的隔离目录不会被当作空白环境重新初始化。

已单独获准的补测服务在 `http://127.0.0.1:18804/parallel-duplex/`，使用 `outputs/parallel-duplex-retest-20261024/` 和另一份机器本地数据目录。启动器支持 `-Port`、`-OutputDirectory`、`-DataDirectory` 以显式选择已授权的独立批次；这些参数不是绕过旧账本停线的自动重试机制。

在连接云端之前，页面先检查约 0.8 秒的真实渲染帧率。已发送过的题目，包括中途停止的录音，不会被整批按钮从头重发。页上提供已保存音频的免费回放和明确标注的人工动作指令预览；后二者不计作真实自由对话验收。

## 谁决定动作

1. 持续 PCM 输入经云端断句和转写进入 WAI，检索记忆并拼装本轮上下文。
2. 语音 Qwen 直接自由回复；需要完整后台解析时，可请求一次 `request_full_reply` 转交。
3. 动作 Qwen 拿到生成前冻结的当前问题、有限已送达上下文、检索片段和数学人物状态。没有预写答案，也不会收到本轮未来回复全文。
4. 动作 Qwen 只能建议 `none/greet/explain/listen/comfort/agree/disagree`，不能设置情绪、力度、速度、关节或任意资源。
5. 本地调度器检查轮次与连接身份、完整参数、状态版本、姿态、手部占用、足部支撑、身体回收、冷却与过期。信息不够就保持当前姿态。
6. 当前请求明确的招呼、解释可以先起势。赞同、否定、安慰还要等真实回复字幕确认，不根据猜测提前表态。
7. 准备动作等待第一个非静音音频样本的实际播放时刻，再继续同一个动作实例；迟到动作走已有媒体调度队列。语音不为动作延迟。
8. 取消撤销本轮播放与候选，原控制器负责自然收回。旧轮的迟到音频、字幕、动作不能复活。

数学情绪来自 `state_bus/runtime_soul` 的实际状态，只读映射到已有温和表情。缺失值不伪造。语音口型仍由真实播放音频驱动，身体动作不覆盖数学表情。

为避免云端把句内停顿当成说完，实验入口会检查已收到 PCM 的最后有声位置：实际尾部静音至少 650 ms，并且没有后续监听分段待完成，才把完整片段送入 WAI。普通云端断句本来就晚于这个门槛的轮次不会再额外等 650 ms。输入断流不能充当静音。检测是保守的能量规则，不是完美的语义断句。

## 动作与资源范围

这是交谈中的动作准入中心，接入原有 `RealtimeScheduler`、播放 owner/epoch 和原动作播放器。它还不是完整的自主闲时生活中枢。

当前只开放已经验收的站姿、空手动作子集：挥手、解释、安慰、点头、摇头。沿用原始动作定义和轨迹；没有修改身体幅度、近身肘部、利落挥手、PMX、头发或裙摆绑定。Stand2 明确禁用；尚未获准自动调度的原生游戏资源不会因为“游戏资源优先”而跳过审核。

## 怎么读测试结果

自动测试音频只包含用户问题，由本地语音合成生成，按原速通过同一个连续输入接口发送。答案没有模板，完全由云端实时生成。测试记忆是四条可核验的合成记忆，数据库和历史与正式用户数据隔离。

报告分开记录：用户最后有声采样、云端断句、最终转写、本轮接纳、WAI 准备、请求发出、第一个有声包、首个有声采样播放、完整动作命令、实际骨骼起势、主动作阶段及取消。首声是 AudioContext 时间，不是扬声器实测声学时间。

仅在完整音频实际播完、准确帧数确认后写入助手已送达历史。打断的回复不算完整交付。后台记忆、纠正与维护仍真实运行，但摄像头、自主心跳和 Neo4j 在隔离实验中关闭。

窗口最小化或页面节流会让动作计时失真，报告保留原值并标为无效；不能拿免费回放替换云端实时记录。本地模拟动作预览也不算自由对话验收。

实际本批结果与尚未完成的部分见 [RESULTS.md](RESULTS.md)。运行时原始证据保存在 `outputs/parallel-duplex-20261024/`，不作为源码提交。
