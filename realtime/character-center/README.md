# 连续表情与角色中枢：首轮小范围接通实验

这是 `2026-10-25` 的实验版本。范围是连续面部控制、现有完整双工语音与记忆链路、少量原生动作，以及一种真实 WAI 后台阅读活动。它是本机已保存的完整接入计划的首轮子集，没有把完整计划的 15 条后台活动、50 轮对话全部执行，也没有把全部素材直接开放。

本文说明接线和实验边界；本批真实调用、失败与修复范围见 [RESULTS.md](RESULTS.md)。身体原有幅度、近身肘部与利落挥手沿用原轨迹；明确禁用的 Stand2 举手姿态及攻击动作仍不开放。

## 谁决定人物怎样表达

| 部分 | 依据与职责 |
| --- | --- |
| 数学底色 | 读取 WAI 数学情绪与有效精力，持续形成基础面部目标。表现模块不修改 WAI 的长期情绪。 |
| 当前交流态度 | 动作旁路模型根据当时有效的用户话语、历史、已知回复内容或真实活动选择关切、认真、轻松等态度。 |
| 短反应 | 模型根据新的有效内容决定一次惊讶、疑惑等反应。结束后回到那一刻仍有效的态度。 |
| 动作配套表情 | 跟随身体真正执行到的阶段；与当前态度冲突的配套脸不参与。旧欢迎动作还在收手，也不能把关切盖回微笑。 |
| 口型与眨眼 | 口型跟随实际音频播放。发音必需通道、嘴角和眼睑分开处理，最终由一个面部合成器输出 PMX 形变。 |

模型选择表达，控制器逐帧兑现。相同意图的修订只改变目标和强度，不重新播放开头；新的相反态度从当前显示形状与变化速度接续。数学更新不取消整轮身体动作，纯面部形变不把整个身体标记为忙。

语义态度的当前工程初值是：20 秒没有新的有效语义确认后，用 5 秒退到低强度注意。退弱不会自动露出先前被压住的开心笑，也不会改写数学状态。新的证据需要模型明确确认才能续期，重绘、旧包重发和数值波动不能续期。这是可以调校的实验参数，不是人类心理规律。

17 份角色原生脸提供源配方、左右差异和合法负值；这不等于所有组合都已通过自然度评审。当前语义到配方的强弱映射也是实验值。原生配方没有覆盖的能力可以明确使用已有原创材料，不把它冒称为游戏原生资源。

## 83 项可选行为，以及仍然有效的规则

当前[目录](catalog.json)包含 83 项：

- 73 项已有交流动作：身体手势与头部、眨眼等行为。
- 2 组原生行为：Stand01 自然站姿、Thinking01 思考。
- 8 项生活动作：坐下、坐着拿书、阅读、翻页、抬头回应、合书、坐着放书、退椅离桌后起身。

模型可以追加、替换或清空身体计划，也可以不动作、重复动作或连续选择多个动作；没有每轮一次、固定冷却或低精力一律禁止的规则。目录中有某项，不代表任何姿态下都能立即执行：实际站坐、支撑、手中物品、已验入口与退出仍需核对。陌生动作名称不能变成临时拼出的身体动画。

83 项也不是所有原生片段的总数。319 段原生身体素材、75 项生活活动、17 份角色原生脸仍按各自的准备和接入状态管理。开始、循环和结束片段不能各自算成一项完整生活行为。

来源撤回、旧轮次、旧媒体身份、资源不就绪及真实身体冲突会阻止执行。它们保护事实与执行一致，不替模型决定“应该安慰还是邀请”。动作被接纳、身体开始运动、声音实际播放和历史完成确认分别记录。

## 声音不等待动作，提前准备不提前演出结论

语音继续使用已有快速回复、记忆检索、按需转交和双工打断路径。动作旁路不拿未来完整台词，动作模型或播放器的回执不成为语音开始的前置条件。

模型已生成的字幕可能领先用户真正听到的声音。用户已经表达的内容可以立即支持表情；依赖助手回复结论的表情需要等待允许的播放边界。当前没有可靠词级音频对齐，不能把字幕到达时刻当成某个词已经说出的时刻，也不能承诺逐词卡点。

用户插话时，旧声音与旧口型按原链路停止，未开始的旧动作与短反应撤销；身体按实际阶段收势。当前有效数学底色和仍适用的话题态度不会因为一句旧回复取消而全部清零。手动预览暂停、音频欠载和真正插话分别处理。

## 后台阅读实际做了什么

实验使用隔离的真实 WAI 生活线程、活动计划与阅读执行入口，读取固定的 NASA 月球事实页面，生成带来源的阅读笔记。测试可以安排材料、任务、输入与撤回事件；不预写人物应该依次做哪些动作，动作由当时的模型决定。

唯一选定页面是 [NASA Moon Facts](https://science.nasa.gov/moon/facts/)。这是读取已选公开页面的正文，不伪装成一次网页搜索。正文来源、抓取时间与摘要指纹保留在本地证据里，下游仍受原有上下文与预算限制。

在使用 `-UseLocalProxy` 时，如果正式 URL 检查因本机代理的 fake-IP DNS 地址拒绝访问，实验适配器只允许这个固定 HTTPS 地址经已经存在的 `127.0.0.1:7890` 代理读取，保留 TLS 校验、禁止跳转并限制最多 600,000 字节。它不接受模型指定的新地址，不修改正式 WAI 的 URL 检查或机器代理设置。

为了在可观看的时间里完成流程，只有后台排期、活动时段和恢复等待采用 30 倍折算，单次活动至少 120 秒。真实模型计算、音频、动画、数学情绪、记忆日期与来源有效期保持真实时间。没有把系统时钟推到未来。

业务开始、暂停、恢复、真实产物与完成分别记录。活动仍在进行不等于模型一直在推理，动作结束也不等于阅读完成。用户介入时先让出注意；恢复前核对来源、当前进度和实际身体状态。来源撤回后，旧成果与旧动作不能因为迟到而重新生效。

语音快路也接收一份冻结的真实活动快照，包括当前状态、实际产物和采样时间。每次发送及最终历史确认重新核验来源；不把正常暂停、恢复或显示版本变化当成撤回。该保护有真实读取成本，单独计时。没有得到有效事实时不让模型靠动作或旧聊天猜进度。

## 本批次范围与封顶

首轮安排 5 条阅读生命周期场景和最多 12 轮对话，覆盖正常完成、请求中介入、产物形成后介入、来源撤回和明确的抓取失败。交叉场景中的用户话语也占用对话轮次，不是额外免费轮次。

底层请求总上限是 228 次，分通道预留：

| 通道 | 最大请求数 |
| --- | ---: |
| 监听与转写 | 18 |
| Qwen 语音回复及必要转交 | 30 |
| 表情、动作与语义更新 | 60 |
| 原有解析、记忆和真实后台工作 | 120 |
| 合计 | 228 |

输入 PCM 连静音最多 480 秒。以上是封顶，不是要求用满，也不是说一个场景只调用一次模型。

已确认响应终态但用量缺失时，账本保留未知及最大预留，不退回额度；在原上限内处理后续请求。无法确认终态或输出边界时冻结相应通道。重启发现未完成预留也会保留未知，不能删除账本后当作没有调用过。全部运行数据、音频、模型资源与凭据留在本机，不属于可发布源码。

## 运行与查看

默认双击同目录的 [Start-CharacterCenter.bat](Start-CharacterCenter.bat)，启动免费本地组件预览：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "F:\AI-Shared\model_test\face\realtime\character-center\Start-CharacterCenter.ps1"
```

默认地址是 `http://127.0.0.1:18808/character-center/`，资源辅助服务使用 18809。页面可选八组手写数学样本、手动选择态度、切换旧版预设与连续原生表情、改变视角和录制原速画面。这些按钮是人工组件验收，不能作为模型自主决定的证据。默认预览不启动真实 WAI 云端对话。

已授权的真实实验使用显式参数：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "F:\AI-Shared\model_test\face\realtime\character-center\Start-CharacterCenter.ps1" -EnableCloud -UseLocalProxy
```

不使用既有本地代理时省略 `-UseLocalProxy`。脚本从本机工作区配置定位运行环境，不在源码中保存密钥。可以指定 `-OutputDirectory`、`-DataDirectory`、`-Port` 和 `-AssetPort`；脚本不会自动清空已有实验数据来重新获得额度。同端口已运行另一模式时会拒绝复用，不停止无关服务。

默认输出在 `outputs/character-center-20261025/`。页面分别显示后台状态、模型决定、身体执行、语音与历史；真实记录回放不再调用模型。合成用户音频与浏览器 WebAudio 可以验证指定链路，但不等同于真人麦克风、回声消除或物理扬声器的验收。

原速 WebM 是当时实际画面的证据。事件重演是调试功能，每次重新加载独立场景，防止旧命令去重和取消记录污染重演；它不能保证与原录像的桌椅、持物和代码版本完全一致。回放页禁止连接云端。

本版需要本机 WAI 工作区和已经准备好的私有 PMX、贴图、原生曲线、脸配方；Git 源码不包含这些素材、密钥、运行数据库或真实记录。语音待播缓冲设为 40 秒，起播提前量仍是 40 毫秒；原服务端单响应 35 秒保护保留。尚未发起生成的预热语音连接闲置 60 秒后重新建立，这只是实验工程策略，不是服务商官方超时承诺。

## 组件验证与证据边界

面部专项检查从 face 项目根目录运行：

```powershell
node --test tests/continuous-face-controller.test.mjs
```

检查包括原生有符号配方、数学状态只读、同意图连续修订、20+5 秒退弱、旧欢迎尾笑不能盖过关切、短反应去重、口型退出、眨眼与兴奋叠加、取消保护和八组本地输入。存在本机私有素材时，还会读取实际 17 份角色配方验证展开与可解析性；没有素材时该项明确跳过。

这些检查只能证明对应控制契约与数值性质。实际首声延迟、动作提前量、记忆纠正、出声中插话，以及角色是否自然，需要另看逐阶段的真实记录和原速画面。本批不完整通过的项目已在结果中明确保留。
