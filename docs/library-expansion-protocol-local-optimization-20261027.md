# 扩库后的本地协议校验优化与旧旁路容量兼容

本轮没有调用云端模型。以下时间只衡量本地 Python 动作命令校验，不是语音首声延迟。DeepSeek 修改只用于已有可选动作旁路的容量兼容，主语音模型及语音流程保持原实现；没有扩大历史批次账本或响应次数。

## 本地命令校验为什么慢

扩库后的目录有 262 项，内部包含完整的资源及几何资料。旧 `parse_actions` 每次校验一条命令，都通过公开的 `load_catalog` 深拷贝整份目录；每个带表现许可的动作还会重新加载一次 `performance.py`。

现在分开公开读取与内部校验：公开 `load_catalog` 仍返回隔离副本，调用方修改它不会污染下一次读取。内部校验只读取动作 ID、执行器和权限，不复制源几何。默认文件及显式文件路径按真实路径、修改时间和大小使用最多 8 个内部缓存条目；文件变化后重新读取，非法版本及文件删除均直接拒绝，不退回旧目录。调用方传入的字典或列表不进缓存，每次重新核对 ID；权限模块每个协议模块生命周期只加载一次。

同一台机器、同一个带 `support-preserving` 许可的动作包，每种方式预热后测 30 次：

| 校验入口 | 修改前中位 | 修改后中位 | 修改后 P95 |
| --- | ---: | ---: | ---: |
| 已加载的完整目录列表 | 75.584 ms | 0.157 ms | 0.771 ms |
| 默认目录文件 | 165.504 ms | 0.562 ms | 1.664 ms |
| 显式目录文件路径 | 137.757 ms | 0.665 ms | 1.348 ms |

前后是连续运行的独立进程，期间机器还有其它离线工作；结果用于定位大量重复复制和导入的影响，不代表稳定负载下的精确倍率。原始逐次记录保存在 `outputs/library-expansion-20261027/protocol-parse-benchmark.json`。

## 旧 DeepSeek 可选旁路为什么拒绝完整目录

在本轮较早的 262 项目录快照上，用真实的旁路组装代码、本地假 WAI 状态和假 HTTP 传输测得以下字节数。之后补充了展开书收合时间、实际物体位置与路线条件，因此下表是保留的定位样本，不是最终请求的固定大小；最终代码仍按每份实际请求检查同一个上限：

| 数据 | UTF-8 字节数 |
| --- | ---: |
| 完整精简动作目录 | 66,230 |
| 完整请求按旧检查方式编码 | 91,160 |
| 旧 aiohttp 默认 ASCII 转义请求 | 109,799 |
| 完整请求用紧凑 UTF-8 编码 | 90,670 |

原目录本身已经超过旧的 65,536 字节上限，删除无意义空白只能节省 490 字节，不能解决容量问题。本轮保留全部 262 项动作、条件、权限和工具说明，将总请求上限明确设为 **131,072 字节**。请求准备时生成不可变 UTF-8 字节，实际发送这份字节，不再由 HTTP 库另用不同编码重组。

新请求的输入预算上界来自同一份冻结字节长度，再加原有 8,192 的协议余量；输出上限仍为 2,048。它是保守预留上界，不是服务商实际计费 token 数。本次 90,670 字节的假请求预留输入 98,862、输出 2,048，完整假响应结算为 `reported`。准备前的类级最坏输入上界为 139,264，具体请求在预算预留前收紧到自身字节数。

超出大小限制会在预算预留和发送前拒绝。边界测试使用中文与 ASCII 混合文本，证明正好 131,072 字节可以准备，多一个字节就拒绝；准备后修改外部消息或可见的请求字典也不能改变实际发送的冻结字节。取消仍继续收取终态用量，未知用量仍保持原有停止和保留预留规则。

## 验证边界

测试覆盖公开读取副本隔离、内部缓存不外泄、输入不被修改、文件时间或大小更新生效、非法目录及删除文件不使用旧缓存、完整扩库跨语言协议一致，以及旧旁路假 HTTP 全链路、取消与未知用量保护。完整回归日志保存在 `outputs/library-expansion-20261027/python-final-clean.log`；请求字节及假预算记录保存在 `outputs/library-expansion-20261027/deepseek-request-size.json`。

对全部 `test_character*.py` 与 `test_parallel_duplex*.py` 执行完整离线回归，较早两轮分别为 **245 passed，69.85 秒**和 **245 passed，16.82 秒**。最终加入展开书的 1.4 秒收合说明及实际道具状态投影后，回归为 **246 passed，27.27 秒**，见 `outputs/library-expansion-20261027/python-final-release.log`。旧日志均保留；机器负载不同，不能将测试完成时间差称为协议加速。这包含新增缓存测试、旧可选旁路的完整假传输，以及既有双工、取消、记忆与历史保护；没有使用云端模型或真实测试批次账本。

模型现在能读到少量实际道具事实：是否展开、书页状态、世界位置与朝向；完整骨骼、源动画几何和私有资源正文仍留在执行器中。旧测试曾要求连道具位置也省略，与本次路线及场景判断能力不再一致；最终将断言更新为保留这些事实、明确排除骨骼和骨骼调色板，并继续检验读取副本不会修改现场。

这些结果没有证明云端模型会自然使用整个新动作库，也没有重新测量语音服务延迟。连续观感、浏览器性能和真人交互由本轮其它验收记录分别说明。
