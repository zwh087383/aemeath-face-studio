# 原生优先动作 Skill 与架构适配实验验收

任务于 2026-10-22 开始，2026-10-23 完成。本批是架构修订与独立实作实验，不是 WAI 全链路已接通的声明。架构正文见 `avatar-flow-wai-adaptation-2026-10-22.md`，对应四页版源文件为同名 HTML。私有 PDF、源资源清单与浏览器证据保留在本机 outputs。

## 交付

- `skills/native-performance-authoring/`：已安装到本机 Codex skills 的可复用技能。以资源事实、合理推断、制作时自选公式分层，先复用原生素材，再重组，最后补缺；包含接缝、口型所有权、打断和真实角色验收要求。
- `preview/core/skill-reaction.js` 与 `realtime/skill-lab/`：独立子代理完整阅读该 skill 后制作“等你改完，再确认”。页面为 `http://127.0.0.1:18793/skill-lab/`，支持原生底层/新层切换和手动事件。不会写入 WAI 情绪或记忆，不调用云模型。
- 架构按当前源码修订：WAI 数学情绪与有效能量为权威源，Qwen 仅提供交流意图；只读状态桥、统一资源注册表和正式合成入口仍是下一阶段工作。

## 独立制作与审阅

制作代理在不继承父代理对话的情况下读取技能、当前资源及允许修改的文件，自行选择“用户改口时收住回应，等补充完成且理解后确认”的缺口。原生 Stand2 与配套 Rib_Stand2、实际模型、既有近身肘部求解器被复用；事件条件化身体与动态眉眼、确认门控及恢复轨迹为新写内容。

检查了当前 583 段动画与 3142 项资源的目录字段、17 个角色表情的 108 条静态曲线，以及七个最近原生身体候选的实际轨迹；另比较 listening_pause、offer_turn、ask_check、clarify、embarrassed、reset_and_resolve、micro_ack 等已有原创候选。新增之处是可等待、可中断、由独立事件决定确认的过程，不把单个点头或复用待机宣称为原创。未逐段人工观看全库，也不保证未提取游戏资源不存在相似设计。

WAI 审计代理与 face 审计代理独立复核，作者据反馈修复并交回文件。实际讨论促成以下架构修订：

1. 直接回复与第二个 Qwen 转交共享逻辑媒体时间；后段 cue 带累计帧偏移，历史仍需全部语音段交付确认。
2. 状态序号属于可信连接建立的 stateStreamId，重连不能让旧流消息复活；闲时活动使用 interaction/activity generation，不伪造语音 responseId。
3. 区分无声的 perform_avatar 失败与合法 request_full_reply 转交；D 方案工具回执的实际时序不能写成“立即回 ok 就能同时出声”。
4. 完整句子时长未知时，词位插值不能承诺零等待的精确同步；音频晚于/早于动作分别有降级策略。
5. 能量读取 runtime_soul 的有效值；当前回合分类未完成时先使用合法已提交快照，不给首音频加等待。

架构审阅的七项具体意见已复核关闭。实作审阅另外修复了正常更正/确认只接续位置而速度归零、取消身份检查不完整、仅“理解”而没有“说完”门控的问题。技能同步吸收这些反例，并增加首帧加载诊断要求。

## 保留的失败与限制

首次作者浏览器等待模型就绪在 120 秒超时；父代理早期版本约 171 秒加载完成并通过 9 项检查，其原始证据单独保留。最终版本包含之后的身份门控、速度衔接和真实 grant 系数修复，最终 11 项证据不与旧结果混用。

速度接续使用数值估计，C1 结论限于测试容差内的参数轨迹，不是最终 IK、蒙皮严格连续性的解析证明。未新增衣发物理或碰撞求解，原生衣发叠加新身体姿态后仍需看穿插。页面的暂停是全局审阅暂停；生产音频停播不应停止本地打断收势。

本批未改 WAI 情绪方程、主语音链路、记忆数据和历史结算；没有云端调用或物理麦克风验收。现有身体幅度、近身肘部与利落挥手实现保留。原始游戏资源、输入 PDF、截图录像及私有数据不进入 Git。

## 下一阶段优先级

先建立只读权威状态桥与兼容旧工具的适配器，再给少量常用原生动作补齐语义、通道所有权和退出条件，最后通过一个合成入口接 D/direct。资源加载移出语音关键路径，缺少资源时保持当前安全姿态。句子对齐、韵律增强与更多新动作应排在这三个基础步骤之后。
