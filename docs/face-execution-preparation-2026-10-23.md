日期：2026-10-23。实验性本地组件，属于动作前期准备。正式语音、记忆、历史和数学情绪来源没有改动；这里没有调用云模型或播放真实语音。

本批复用已有表情，补上动态出现、保持、退出和撤销。它没有新增100种表情，也没有把现有独立播放器冒充统一人物调度器。原生身体、生活动作、持物和完整连续活动仍在另行准备。

## 当前能直接看什么

本机页面为 <http://127.0.0.1:18797/face-preparation-lab/>。选择持续底色，再点短表情；过程中可以换底色、取消、暂停，或打开模拟发音嘴形。取消和自然结束都会靠近最新底色，不会把持续情绪清空成中性脸。

底色在此页由人手选择。接正式系统时，应由现有数学情绪系统给出基调，本模块不自行推断开心、疲惫或关系变化。表情的含义也不由文件名自动批准。

原生Stand2、精确配套衣发和已有裙片绑定作为显示底层。表情只写PMX顶点形变，没有修改动作骨骼。原配方的头部倾斜、材质脸红和非顶点控制在本页明确省略，不能把它们算成已实现。

## 资源数量怎样理解

资料包含17份角色原生表情、43份默认脸资料和40份已有原创配方，共100份来源记录。实际87份有顶点映射，加上一个有效的自然底色配方，共88份可以人工预览；另12份缺映射，保留资料但不提供错误播放。

默认脸里包含其它角色或通用资源，映射存在也不能证明适合爱弥斯。原生完整脸与说话时裁剪版本共用原记录，不另算新表情。所有自动使用许可仍为零。

## 程序实际怎样处理

| 环节 | 谁决定、依据是什么 | 实际变化与无法确认时的处理 |
| --- | --- | --- |
| 持续基调 | 当前页面手选；未来由既有数学系统提供权重及递增版本 | 新基调从当前显示权重和速度接入；旧版本不能覆盖新版本 |
| 短表情 | 当前页面明确点击；正式接入需要可信事件或有效模型建议 | 使用原生曲线或已有配方，安排出现、保持和退回；无映射就拒绝，不把旧脸当成新效果 |
| 中途换表情或取消 | 本地核对表达归属、代次和表达编号 | 保留当前权重与变化速度，随后靠近新目标；取消不会瞬间清零 |
| 同一轮多次表达 | 同一归属下使用不同表达编号 | 新编号可以继续，同编号重复被拒绝；整轮撤销后迟到编号也不能复活旧表达 |
| 语音嘴形 | 播放方明确声明是否持有发音部位，提供口型值 | 已识别嘴部叶形变全部交给口型。缺少该口型通道时为零，不让短表情代填发音 |
| 暂停 | 本地预览时钟 | 精确保留表情状态；不因零时间重复绘制产生微小漂移。恢复与真实语音时钟的接线仍属后续工作 |
| 来源变化 | 本地核对资源、模型和程序文件内容 | 清单、具体原生表情、PMX或依赖代码变化后，旧准备资料不能继续当作当前证据 |

PMX组合形变先展开为真实叶形变，保留负值和比例。说话时采用保守规则：凡实际改变发音顶点或属于嘴部的叶形变，都归口型。因此有些原配方的嘴角或混合眉形会被省略；不声称此版本已经解决了所有发音与微笑并存的美术问题。

出现与退出由本地有状态计算完成：它记住当前值和变化速度，目标改变后继续运动并收稳。默认采用约0.3秒出现、至少1.2秒保持、0.45秒退回；较长原生动态曲线默认完整走完再退出。需要短演出时，调用者可以明确指定时长。这些是本次试调参数，不是已经恢复的游戏原始公式。
