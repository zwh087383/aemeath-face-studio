状态所有权与接口

角色的情绪，只有一个来源。

内部实际分为四维情绪 E=[V,A,D,S] 与二维关系 R=[L,T]。分类模型提供事件类型和强度，数学系统综合人格、关系、压力、惯性、后效与时间回归。模型可以间接影响情绪，但不能任意设置最终向量。

E_next = baseline + (E - baseline) × exp(-dt / tau_effective)

这是已有回归核心的简写，不替代完整事件结算。关系与有效能量有各自机制；启用 V2 life 时，能量还可能由作息合成。

状态谁提供影响什么
持续情绪 / 关系WAI 数学系统表情基调、动作幅度范围、恢复与稀疏程度
有效能量 / 睡眠与本轮回复同口径的 runtime_soul动作预算与体态；不能取任意 tool.energy
短期交流意图已校验工具、可信交互事件解释、道歉、让话、确认等行为候选
实际执行状态导演 / 播放器姿态、速度、占用层、播放进度与取消

新增只读桥，不增加快答前置等待

  • 首轮先用上一有效权威状态；本轮后台分类合法提交后再平滑更新。
  • 状态包含版本、会话、状态流身份、递增序号、采样时间与有限公开数值。跨进程时钟先转换。
  • 重连通过可信握手取得新状态流与快照，拒绝旧流在途消息；不能仅将同一会话序号归零。
  • 当前快照并没有这些新字段。桥需要实施，不能声称“现有字段直接订阅就行”。

工具是短期建议，不是情绪赋值

先兼容现有 perform_avatar；后续工具可采用 communicativeAct / keyAction / timing / anchor。宿主添加身份、时间、有效期和优先级，模型不传骨骼轨迹或跨轮情绪。

D 方案的已实现顺序：音频即时转发 → 完整工具校验并提交本地 → response.done 后发工具回执。不能将它改述为“立即回 ok 已经验证”。

动作接纳、动作开始、动作完成、语音完整播放是四种不同回执。动作回执不能替代语音 ACK 或触发完整助手历史写入。仅动作工具未出声要如实记录；合法 request_full_reply 仍允许零音频首段转交 Qwen2。

时间、资源与身体合成

音频管同步，本地管连续。

语音绑定动作与口型

跟随实际消耗的媒体帧。暂停 / 欠载时不推进。收到或排入队列的字节不是已播放量。

倾听、闲时与打断收势

使用本地单调时钟。音频停止不冻结身体；数学情绪仍由 WAI 自己的时间推进。

直接回复转交 Qwen2 时，保留两个物理响应身份，共用一个逻辑媒体时间线。第二段动作加入 startFrame / sampleRate 偏移；取消及最终 ACK 覆盖整组回复。

短语对齐要承认实时因果限制

“句内字数比例 × 整句时长”需要知道整句最终有多长。句子还没结束时，这个长度只能预测，不能承诺同时零额外缓冲、精确提前命中。

  • 优先采用开播 / 结束事件和原生动作准备段；短语确定且余量足够才使用锚点。
  • 提前量按动作准备段设置，不统一减 200ms；before_speech 晚到时降级，不让语音等动作。
  • 迟到的非必要动作丢弃；否定词、引用和思考停顿不直接触发摇头或点头。

新意在交流过程、分支与衔接，不声称“点头”是原创。检查现有游戏与原创近邻，未穷尽整个游戏的语义。该页为独立本地事件实验，未接正式 WAI 或云模型。

打断保护继续沿用已有原则

  • 可信 barge-in 立即撤权、停止旧音频并清旧 cue；身体可平滑完成安全收势，不能等动画中断点才停声。
  • 取消回答不取消用户输入事实。已接纳的纠正和合法数学更新保留，旧 input_generation 结果仍拒绝。
  • 语音动作使用 response owner；倾听 / 闲时使用交互 / 活动 generation，不伪造 responseId。
  • 闲时适配 WAI 已有活动模块，恢复前核对步骤、场景和新任务，不另建永久 LLM 计划循环。

建议实施顺序

  1. 只读状态桥与旧工具兼容层：保持语音、记忆、历史结算；不等待新增分析。
  2. 原生常用资源注册表与统一合成入口：先让少量高质量资源可靠进入现有 D / direct。
  3. 增强对齐与受控选择：再引入短语置信度、韵律和少量非重复反应。

验收必须区分证据等级

本轮检验 skill、离线状态机和真实模型预览；正式状态桥、完整云语音、个人记忆、物理麦克风与声学停声需后续独立验收。自动轨迹指标和静态截图不能替代连续观看的自然度判断。
