# 动作前期准备资料

这批资料将原生资源、已有原创控制器和表情整理成统一的可检查目录。工具只读现有资源；测量结果和游戏数据留在本机 `outputs/action-preparation-20261023/`，不随Git提交。

每条记录说明来源、用途及其证据、触发、前置与禁止条件、进入/退出/取消办法、测量结果和缺口。用途尚来自名称推断时直接标明。原始片段、行为家族、衣发、表情、道具和原创动作分别统计，不能将它们相加称作独立身体动作数。

使用状态必须区分：数值已测、控制器采样已做、当前模型已看、组合与打断已验、正式自动使用已批准。当前准备目录不授予自动使用许可；没有数据或出口的资源保留为明确缺口。

本地生成顺序：先运行 `scripts/action-preparation/prepare_native.py`、`prepare-authored.mjs` 和 `prepare-expressions.mjs`，再运行 `build-catalog.mjs`。具体输入与依赖见交付文档。后续修改源动作、绑定或控制器时，相关测量与验收失效，需要重新检查，不能沿用旧“通过”标签。
